# SRE - Observability

Implementation of a complete observability stack using Open Source tools.

## Components

* **Metrics:** Prometheus + Grafana Mimir
* **Logs:** Grafana Loki
* **Traces:** Grafana Tempo
* **Collection:** OpenTelemetry Collector
